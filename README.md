# person

A small C++ `Person` class meant to be extended by other classes that need
to represent a person.

## Branches

- `main` — active development.
- `demoTesting` — where in-progress changes get tried out before they're
  considered stable.
- `stable` — the last known-good, working version; only fast-forwarded from
  `main` once a state has been confirmed stable.

## Base status (this branch)

This is a starting point, not a finished library. Currently `Person` holds:

- Name (first / middle / last)
- Age
- Major
- `idN` — a unique ID, auto-generated by the class itself (a static counter
  assigns the next ID on construction); it is never passed in by the caller
- `clearance` / `Access` — commented out for now (enum, member, constructor
  parameter, `getClearance()`, and the admin-only checks in the setters
  below); disabled, not deleted, so it's easy to bring back

Known rough edges, left as-is for now:

- `updateName` / `setMajor` / `setAge` still take a "modifier" `Person`
  parameter for the (currently disabled) admin check; it's unused for now.
- No build system yet; compile the two files directly.

## Build

```sh
g++ -std=c++17 -Wall -Wextra -c Person/Person.cpp
```

## Usage

```cpp
#include "Person/Person.h"

Person alice("Alice", "", "Smith", "Computer Science", 20);
alice.getIdN();    // unique, assigned automatically
alice.getFullName();
```
